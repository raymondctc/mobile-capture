Mobile Capture Android frontend notices

The frontend uses generated shadcn components, Radix UI, Tailwind CSS, Lucide,
React, and the other packages listed in provenance.json. The adjacent files are
copies of their distributed license texts or, where a package omits a license
file, its original package metadata and README license declaration. The standard
MIT text is included with the other MIT packages. Geist and Geist Mono are bundled
locally under the SIL Open Font License 1.1. Their OFL files are included here.

create-tauri-ui 1.2.0 generated the reference frontend with shadcn 4.16.1,
base radix, preset nova, and emitted style radix-nova. This app adapts that actual
generated source. No source license is invented for the generator repository.
The generated shadcn source is covered by the included shadcn MIT license.
The existing native dependency license inventory is separate and unchanged.

provenance.json records exact package versions, source hashes for the copied
components, local font hashes, font licenses, and the original app icon hash.
